# Pilum: alpha builds

**The known worlds end where your outpost stands.** Pilum is a tactical RTS of frontier colonies and war, in early alpha.

**Download:** [latest release](https://github.com/PilumRTS/pilum-releases/releases/latest) for Mac (Apple Silicon and Intel) and Windows 10/11.

- Mac: open the `.dmg` and drag Pilum into Applications. It isn't notarized yet: on first launch, open System Settings → Privacy & Security and click **Open Anyway**.
- Windows: SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

The game checks this repository for updates (`latest-mac.json`, `latest-windows.json`).
